OWNER ACCESS

Document management.

Upload and delete documents using your GitHub account. GitHub checks your sign-in and repository permissions before saving changes. Visitors can read published PDFs; only accounts with write access can change this library.

Upload PDF documents ↗ Manage / delete documents ↗
  1. Sign in to your GitHub account when requested.
  2. Upload PDF files to the documents folder and confirm with Commit changes. If a branch review is required, merge it into main to publish.
  3. To delete a document, open it in that folder, select Delete file from the file menu, and confirm the change on GitHub.

Every PDF saved to this folder is public. You can remove all PDFs to leave the library empty. Files in other portfolio sections are separate.

Deleting a file removes it from the current library; previous versions can remain in Git history. Upload public documents only.
